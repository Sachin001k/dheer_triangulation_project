Theoretical Foundation

Chvátal's Art Gallery Theorem

The Art Gallery Problem asks: how many guards are needed to see every point in a polygon? Václav Chvátal proved:

For any simple polygon with n vertices:
⌊n/3⌋ guards are necessary and sufficient

Algorithm Steps

1. Triangulation (Ear-Clipping)

Decompose the polygon into n-2 triangles by repeatedly finding and removing ears (triangles with two edges on the polygon boundary).

  • Time complexity: O(n³)
  • Output: Valid triangulation for any simple polygon
  • Verification: Triangle count = n-2

2. Three-Coloring (BFS)

Color the triangulation's dual graph with 3 colors such that no two adjacent triangles share the same color.

  • Builds triangle adjacency graph
  • Uses breadth-first search (BFS)
  • Guarantee: All 3 colors appear (from Chvátal's theorem)

3. Guard Selection

Select the smallest color class as guard positions. This minimizes the number of guards while guaranteeing coverage.

  • Guard count ≤ ⌊n/3⌋ (smallest of 3 classes)
  • Coverage: Every triangle contains a guard vertex
