🎨 Polygon Visualization Guide

Understanding Lines, Colors, and Symbols

📐 Line Types Explained

🔲 BLACK SOLID LINES
These are the polygon edges (outer boundary). They form the original shape you're analyzing.
• Thickness: 2.5 pixels (bold, prominent)
• Color: #000000 (pure black)
• Function: Define the polygon perimeter
• Added by: Given input (not added by algorithm)
✦ GRAY DASHED LINES
These are the triangulation diagonals. They divide the polygon into triangles.
• Thickness: 1.5 pixels (thin, secondary)
• Color: #999999 (gray, less prominent)
• Pattern: Dashed (5px dash, 5px gap)
• Opacity: 70% (slightly faded)
• Function: Create triangles inside polygon
• Added by: Ear-clipping triangulation algorithm
🟠 ORANGE BORDERED BOX
This marks a guard position. A guard at this vertex can see all triangles.
• Color: #FF4500 (bright orange)
• Width: 3 pixels (stands out)
• Symbol: Box around a vertex
• Function: Highlight where guards are placed
• Count: Usually ≤ ⌊n/3⌋ guards total

🎨 Vertex Colors

Red: Color Class 1
Green: Color Class 2
Blue: Color Class 3

Each vertex is colored based on a three-coloring algorithm. This ensures that no two adjacent triangles share the same color. Guards are selected from the smallest color class.

📖 How to Read a Polygon Visualization

Step What to Look For What It Means
1️⃣ Black solid lines Original polygon shape (outer boundary)
2️⃣ Gray dashed lines Internal diagonals that create triangles
3️⃣ Colored circles Vertices labeled with numbers (0, 1, 2...)
4️⃣ Orange boxes Guard positions (vertices that see all triangles)

✅ Verification Checklist

  • Black solid lines form a closed loop
  • All vertices have colored circles with numbers
  • Gray dashed lines divide shape into non-overlapping triangles
  • Triangle count = n - 2 (for n vertices)
  • All circles are red, green, or blue (no uncolored vertices)
  • Orange boxes mark guard positions
  • Guard count ≤ ⌊n/3⌋ (theoretical bound)

📌 Example: Random 8 Polygon

Black Lines: 8 edges connecting 8 vertices in a closed loop
Gray Dashed Lines: 6 diagonals creating 6 triangles (8-2=6)
Colored Circles: 8 vertices colored red (2), green (4), blue (2)
Orange Boxes: 2 guards placed at specific vertices
Result: 2 guards ≤ ⌊8/3⌋ = 2 ✅

🚀 Quick Reference

Element Style Color Meaning

Diagonal Dashed Line Gray Internal triangulation line
Vertex Circle Red/Green/Blue Polygon vertex (colored)
Guard Box Outline Orange Guard position indicator
